## 0. 平台定位与运行方式

| 项 | 内容 |
|---|---|
| 定位 | EEG（脑电）数据处理与建模平台：**数据导入 → 预处理 → 特征/网络 → 训练 → 结果分析 → 统计分析** 的完整闭环 |
| 形态 | PyQt6 桌面 GUI（5 个功能页）+ 同构命令行（配置驱动，可脚本化复现） |
| 层次 | `core/`（纯算法，不依赖 PyQt，可被脚本独立调用）/ `ui/`（只做展示与事件） |
| 数据模态 | EEG 时间序列为主；另支持"表格/矩阵"形态的脑网络（T1 协变、ASL/PET 相似性、外部连接矩阵）与可选 NIfTI 影像 |
| 依赖 | Python 3.13 / MNE / PyTorch / scikit-learn / PyQt6 / pyqtgraph / scipy / YAML + SQLite |

```bash
# GUI
.venv/bin/python main.py

# 命令行（与 GUI 完全同构）
.venv/bin/python -m core.pipeline configs/preprocess_bnci2014001.yaml   # 预处理
.venv/bin/python -m core.cli train configs/train_csp_lda.yaml           # 训练
.venv/bin/python -m core.cli list                                       # 实验列表
.venv/bin/python -m core.cli report experiments/<exp_dir>               # 实验报告

# 功能自检 + 演示（本文所有实测数字的来源）
.venv/bin/python docs/demo_features.py            # 全部 16 组
.venv/bin/python docs/demo_features.py 模型 时频   # 只跑含关键字的组
.venv/bin/python -m pytest tests/ -q              # 361 项单测
```

## 2. 数据导入

**功能**：读取数据集 → 统一成 MNE `Raw`（Volt 单位）+ 语义化事件标注 + 元信息。

**实测（BNCI2014001，本机真实数据）**

```
✔ BNCI2014001：被试 [1..9]，session T/E
✔ 被试 1 T：22 通道 / 250 Hz / 288 trial / 时长 2687s
✔ 官方 22 导联表（末 4 个 = ['P1','Pz','P2','POz']；无 Oz/CP5/CP6）
✔ 类别 {'left_hand': 72, 'right_hand': 72, 'feet': 72, 'tongue': 72}；cue 偏移 = 2.0s
✔ PhysioNet 纯想象 run = [4, 6, 8, 10, 12, 14]（R04/08/12 想象左右手、R06/10/14 想象双手双脚）
✔ run→任务映射符合官方分组（R05 真实、R06 想象）
```

**要点**

- BNCI2014-001 的 `trial` 字段是**试次起点（注视点）**，cue 箭头在其后 2 s；加载器把事件放在 `trial + 2 s`，因此标准 MI 分段 `0.5–2.5 s` 对应 `trial 后 2.5–4.5 s`（`configs/*.yaml` 里的 `CUE_OFFSET_S`）。
- 一个 `.mat` 里**前 3 个 run 只有 EOG、没有标签**（`trial` 为空），加载器自动跳过；288 个 trial 来自后 6 个 run。
- PhysioNet 是"每个任务占每 4 个 run 里的同一个"（R03/R07/R11 同一任务），**不是相邻两两配对** —— 这一点曾经写错，见第 17 节审计第 2 条。
- 通道名规范化：`Fc5. → FC5`、`Cz.. → Cz`、`Poz. → POz`（供 standard_1005 定位）。

### 3.1 逐算子说明与边界

| 算子 | 做什么 | 关键参数 | 边界/注意 |
|---|---|---|---|
| `set_montage` | 导联定位：标准名（standard_1005/1020…）或**自定义坐标文件**（.elc/.csf/.sfp/.hpts/.csv…） | `montage` | 匹配到的电极坐标会写进 `meta.json`（`channel_positions`），供地形图/3D 网络复用；未匹配的通道只警告不报错 |
| `pick_eeg` / `drop_channels` | 选道/删道 | — | — |
| `mark_bad_channels` / `interpolate_bads` | 标坏道（幅值/方差/谱外）与插值 | `thresh_uv`, `method` | 插值需要导联坐标 |
| `notch_filter` | 工频陷波（50/60 Hz 及谐波） | `freqs` | 数据 60 Hz → 填 `[60]` |
| `bandpass_filter` | FIR（零相位）/ IIR 带通，也可只给一侧做高通/低通 | `l_freq`, `h_freq`, `method` | 长数据 FIR 需要足够长度（会自动缩短过渡带） |
| `gaussian_filter` / `resample` / `normalize` | 平滑 / 重采样 / 逐道归一化 | — | — |
| `re_reference` | **5 种**：`average`(CAR) / `channels`(指定参考) / `bipolar`(双极对，会新增通道) / `rest`(无穷远，球模型近似) / `projection`(可逆投影) | `mode`, `channels`, `pairs`, `rest_alpha` | `rest` **需要电极坐标**（先 `set_montage`）；球半径按电极分布自适应，避免前额电极落到球外产生 NaN |
| `reject_bad_segments` | **连续坏段检测**：滑动窗峰峰值 + 平坦段 → 写 `BAD_segment` 注释 | `win_s/step_s/thresh_uv/flat_uv/min_dur_s/ch_frac` | 检测结果写 `ctx`（段数/秒数）并进报告；分段时按注释拒绝（可关） |
| `clip_outliers` | **去极值**：样本级幅值裁剪（MAD/σ/分位 + 绝对下限） | `mode/k/min_uv/scope` | 有下限保护，正常脑电不会被裁；裁剪点数进报告 |
| `artifact_regression` | **回归法去伪迹**：用 EOG/最前额通道估计并回归掉眼动成分（限频带） | `proxies`, `band_lower/upper` | 无 EOG 且只有普通额区电极（如 BNCI 的 Fz）时会提示"可能连真实额区脑电一起去除" |
| `ica` | ICA 拟合 + **5 判据自动识别伪迹成分** | `n_components/method/min_hits/exclude/autodetect_artifact` | 判据：峰度、1 s 自相关、额区（眼电代理）相关、肌电高频比、幅值比；每条判据都要"超阈值 **且** 成分间离群"，并限制**最多剔除 40%**；界面可逐个看地形图/时序后勾选 |
| `epoching` | 事件分段（可用滑窗退化） | `tmin/tmax/baseline/reject_by_annotation/classes` | 坏段注释**不会**被当成类别；按注释拒绝的 trial 数进报告 |
| `amplitude_reject` | 逐 trial 峰峰值阈值 | `threshold_uv` | PhysioNet 噪声大，默认 500 µV |
| `reject_outlier_epochs` | 逐 trial 峰峰值/IQR 离群剔除 | `metric/iqr_k/per_channel` | 与阈值剔除互补 |
| `euclidean_alignment` | 逐被试 EA（无标签） | — | 见第 17 节审计第 4 条（必须逐被试） |

### 3.2 ICA 成分自动识别的实测依据

在合成"眨眼（额区强）+ 肌电爆发（颞区高频）"数据上，诊断指标与判定结果：

| 成分 | 峰度 | 1 s 自相关 | 额区相关 | 肌电比 | 幅值比 | 方差占比 | 判定 |
|---|---|---|---|---|---|---|---|
| IC 0（眨眼） | 20.4 | −0.06 | 0.87 | 0.00 | 152.3 | 10.0% | ✔ 剔除（峰度 + 幅值比） |
| IC 8（肌电） | 57.4 | 0.04 | 0.01 | 0.50 | 90.7 | 10.0% | ✔ 剔除（峰度 + 幅值比） |
| 其余 | −1.5…3.0 | 0.94…1.00 | 0.03…0.42 | 0.03…0.15 | 2…13 | 10.0% | 保留 |

真实 BNCI 数据上（无 EOG、只有 Fz 作代理）也能给出候选（成分 6：峰度 4.7），并在日志里写明理由。

**实测**

```
特征表 FEATURES（13 项）：['AP','APR','DE','SHE','SPE','C0','NSI','HOC','DASM','RASM']…
✔ 绝对频带功率 (N,C,B) = (8,4,2)；alpha 均值 30.7 µV²
✔ 相对频带功率各频带之和 = 100.0000%
```

## 5. 数据集、归一化与增强

**实测**

```
归一化模式（14）：zscore_channel / zscore_epoch / minmax_channel / minmax_pm / minmax_epoch /
                  minmax_pm_epoch / p95 / x_div / iqr / quantile / alaw / ema / zero_mean / none
✔ 防泄漏：统计量只来自训练折（用同一统计量变换测试集）
✔ 逐被试 EA：各被试协方差偏离单位阵最大 0.004
✔ 数据增强（平移 8 点 + 高斯噪声 0.1 + 通道 dropout 0.1）输出形状 torch.Size([8, 8, 256])
```

**要点**

- **防泄漏**：`compute_norm_stats(X_train, mode)` → `apply_normalization(X_test, mode, stats)`，测试集绝不参与统计。
- EA 采用**逐被试**对齐（每个被试的协方差各自对齐到单位阵，实测残差 0.004）。
- 增强在训练循环里**在线**做（每个 epoch 现场随机施加，不落盘、不进入测试集）。

### 6.1 自定义模型（"以内置定义为基础改写 → 检查 → 保存"）

**实测流程**

```
✔ 自定义模型检查：输入 [2,1,8,500] → 输出 [2,4]，14 层 / 2.7k 参数，目标类别数 4 一致
  逐层维度追踪（前 4 层）：(2,8,8,500) → (2,8,8,500) → (2,16,1,500) → (2,16,1,500)
✔ 保存为新模型 → demo_eegnet_pyramid.py（训练页下拉框即时可见）
✔ 训练路径可直接构建该自定义模型，输出 (2,4)
✔ 类别数写错的代码被拦下：输出维度不对：期望输出 (batch=2, n_classes=4)，实际 (2,5)…
✔ 时窗太短时的报错可操作：→ 最常见原因是输入时窗太短…
✔ 删除自定义模型生效
```

**检查器 `check_code` 做四件事**：① 执行代码并找出对外 `nn.Module` 类（`__model__` 优先，否则取最后一个）；
② 按当前数据的 (类别数, 通道数, 采样点) 实例化；③ **真跑前向**并用 hook 记录**逐层输入/输出形状与参数量**，
校验输出必须是 `(batch, n_classes)`、无 NaN/INF、中间特征不出现 0 维；④ 反传一次，找出"没参与前向的悬空参数"。

**保存后的模型**：`models_custom/<名字>.py`（可直接再编辑）+ `.json`（基础模型/说明/创建时的维度），
训练页下拉框即时出现，`查看模型定义` 可直接看源码。

## 7. 划分协议（10 种）

**实测（3 被试 × 2 session × 4 类 × 12 trial = 288）**

```
协议               折数  train   val  test  泄漏检查
session           3     40     8    48  ✔ train/val/test 互不重叠
loso              3    163    29    96  ✔
session_kfold     6     40     8    48  ✔
kfold             9     54    10    32  ✔
within            3     54    10    32  ✔
few_shot          3     16     0    80  ✔
subject_kfold     3    163    29    96  ✔
holdout           1    195    35    58  ✔
block             8     39     8    49  ✔
custom            1    163    29    96  ✔
```

| 协议 | 语义 | 用途 |
|---|---|---|
| `session` | 逐被试 T 训练 / E 测试 | 跨时间稳定性（标准 BCI 基准） |
| `loso` | 留一被试（其余被试全部 session 参与训练） | 跨被试泛化 |
| `subject_kfold` | 被试分组 k 折 | 跨被试 k 折（论文里写作 5-fold cross-subject） |
| `session_kfold` | 所有 session 有序组合各一折（T→E、E→T） | 消除方向偏好 |
| `kfold` | **逐被试**分层 k 折（不同被试不混切） | 被试内性能上限 |
| `nested_cv` | 外层同 kfold，内层再切 inner_k 选超参 | 消除"用测试集调参"的乐观偏差 |
| `within` | 每被试一折，按 `train_percentage` 抽训练集 | 对齐 EEG-FM-Benchmark |
| `few_shot` | 每类 n_shot 个训练样本，其余测试，可重复采样 | 少样本校准曲线 |
| `block` | 按记录块（run）划分 | 同一 block 内相邻 trial 不跨训练/测试 |
| `holdout` / `custom` / `cross_dataset` | 单次随机切 / 手填受试者 / 跨数据集迁移 | 快速调试、自定义协议、域迁移 |

2. **在每个文件里定位"参数区"小节**：按「Implementation details / Experimental setup /

   实验列表备注里留一行「参数来源: xxx（补充材料）· 取自 S2 Implementation details」。

## 9. ERP 分析

**实测（合成 ERP：target 条件注入 25 µV 的 P3）**

```
✔ 叠加平均（条件 target，n=60）→ (4, 250)
✔ 多条件叠加 → [('std',(4,250),60), ('target',(4,250),60)]
  平均波形成分：N1 112ms/-0.8µV，P2 164ms/0.8µV，N2 244ms/-0.3µV，P3 420ms/26.0µV
✔ 逐试次成分提取 → amplitude (120, 4)
  P3 幅值检验（std vs target）：t=-82.9，p(FDR)=4.12e-106，d=-15.1
✔ 注入的 P3 条件差异被检出（t<0、FDR 后 p<0.001）
✔ 未注入差异的 N1 效应量很小（|d|max=0.18）
```

**流程与用法**

1. **分段**：信号分析页设 tmin/tmax/最多 epoch（可用 annotations 或滑窗）；
2. **叠加**：勾「基线校正」（tmin<0 用 tmin~0 作基线，tmin≥0 用前 200 ms 近似）、勾「多条件对比」把所有条件叠在一张图；
3. **波形图**：主图 + 成分峰值标注，可切换通道或全通道平均；
4. **提取成分**：默认 N1/P2/N2/P3（窗口与极性可改），平均波形给潜伏期/幅值表，逐试次给每个 trial×通道的幅值与潜伏期；
5. **统计分析**：对成分幅值/潜伏期做条件间检验（独立/配对 t 或置换检验）+ **FDR 校正** + Cohen's d + 效应量等级，结果表可导出 CSV；
6. **地形图**：成分窗口内的头皮分布（需导联坐标）。

**怎么用**（GUI 步骤）

1. 「打开文件…」选择变量表（`.csv / .txt / .tsv / .xlsx`；`.xlsx` 需 `pip install openpyxl`），
   或先用「影像 + 图集」提取出"每 ROI 一个数值"的表；
2. 「分析类别」选 **变量关联（RF 重要性 + Pearson + LMM）**；
3. 选**目标变量**（默认最后一列）、必要时选**分组变量**（文本列如被试编号会被优先列出，标注"适合分组"）；
4. 选效应模型（LMM/OLS）、树数，按需勾选 **标准化** / **对正偏变量取 log10** / 标注项；
5. 点「计算」→ 三联图 + 右侧"效应/重要性一览表" + 日志（含 RF 的 R²、随机截距方差、奇异提示）；

**三条使用要点（都写进了界面提示与日志）**

- **相关 ≠ 因果**：中间矩阵只描述共同变化；LMM 提供的才是"控制分组后"的效应方向与显著性；
  而 RF 重要性**本身不含方向**（树只关心怎么划分）。
- **正偏重尾指标（频带功率、丰度）建议勾"取 log10"**：不勾时少数极端样本会主导 MSE，
  实测 RF 的 R² 会从 0.83 掉到 **−0.001**，日志会明确警告"重要性排序仅供参考"。
  注意收益主要来自**目标变量**的重尾被压缩（随机森林对自变量做单调变换本来就不敏感）。
- **同一单元重复观测必须填分组变量**：忽略它会把你"被试间差异"错算成变量效应。
  `tests/test_linked.py::test_lmm_beats_ols_when_group_effect_confounds_predictor`
  用一组合成数据量化了这一点（伪相关被压下去）。

+ 三张整洁表 + 绘图，纯 numpy/sklearn/statsmodels，不依赖 Qt）；
